Sunset Cover Studio — turn your photo into a striking multi-panel poster cover with bold caption lettering and a sunset or neon colour grade, then export it as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Upload your own photos (they never leave your machine), pick one of four panel layouts, a colour grade and a lettering style, drag each photo to crop and position it, and export in one click. Runs fully offline in a desktop browser from its own static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
